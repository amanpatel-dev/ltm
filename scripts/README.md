# Scripts

| Script | Purpose |
|---|---|
| `check_environment.sh` | Basic tool / path checks (adapted from shared lab style) |
| `run_ltm.sh` | Submit **v1** hard-coded LTM job |
| `run_ltm_v2.sh` | Submit **v2** paper-style LTM job |
| `show_ltm_rounds.py` | Local LTM round preview + optional PNG frames |

Make executable inside WSL:

```bash
chmod +x scripts/*.sh
```
